Trigger:
- On Python 3.12, `dataclasses.replace` fills every InitVar that has a default and wasn't passed by calling `getattr(obj, "workspace")`.
- That used to read the class default, None. It now hits the property, which warns and returns `self.evidence`.
- The rebuilt `__init__` therefore receives `evidence=E, workspace=E`, and `__post_init__` raises "SegmentSpec takes evidence or the deprecated workspace, not both".
- The shipped caller is `agents/adjudication/agent.py:117` (`replace(seg, rules=impacted)`). It runs when `changed_fields` is set and a segment's impacted rules are a strict subset of its rules.
- `pipelines/steps.py:2022` builds every segment with `evidence=EvidenceScope(...)` in tools mode and passes `changed_fields=changed` on a rerun.
- Result: a changed-field rerun in tools evidence mode crashes in adjudication.
- The new test reads `.workspace` but never calls `replace`, so it does not catch this.
- Fix options: pass `workspace=None` at agent.py:117, or have the property return None when it is read on behalf of `replace`. The simplest is to drop the property and keep the InitVar.
