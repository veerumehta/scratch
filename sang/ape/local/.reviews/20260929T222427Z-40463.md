So the matrix evaluator can score a bool cell SATISFIED and `compose_caps` then moves it to `unresolved`. With the real evaluator, every cell that reaches `resolved` has already been through `_number(cell_value)`: a cap rule always has a `compare_field`, and an N/A cell returns before that call. So the filter only ever catches the bool case, and it catches that one inconsistently. The fix is no bigger: `try: _number(cell) except (TypeError, ValueError, ArithmeticError)`, the same guard used for `raw` a few lines below.
