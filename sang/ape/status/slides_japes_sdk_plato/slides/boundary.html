Design principle

The boundary is enforced, not asserted

One direction

Plato imports the SDK; the SDK never imports Plato. CI checks it.

Two clocks

An SDK version names an API; a Plato version names a deployed image.

Separable

Plato can move to its own repository as a mechanical split.

Japes SDK and Plato

07

Why this matters: teams that import the SDK directly, like jaci, are never forced to take a Plato change, and a Plato deploy is not forced by every SDK release. The import direction is checked by an import linter in CI, so it cannot erode quietly.
