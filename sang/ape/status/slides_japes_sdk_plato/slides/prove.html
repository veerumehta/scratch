The pack earns live work on gold cases

Gold cases

Typed inputs with expected results, written before tuning. The harness runs each end to end against a pass threshold the pack declares.

Deterministic assessment

Every rule checked against a record, the binding rule named, one attestation per rule. No model involved.

Formal checks

Z3 checks compiled from the same canonical policy, one attestation per claim. Local today; deployed once an isolated job service is in place.

Proof comes from the policy itself, not from asking a model whether it complied.
