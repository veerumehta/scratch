This is the compounding loop. Feedback on a hosted assistant is submitted, processed, reviewed, and can be added to an evaluation dataset as a case. Experiments compare a change against a baseline. Prompt optimization picks a winner and applies it to the tenant's pack draft on request. It never publishes: the next version goes out through the same check and publish path as the first.
