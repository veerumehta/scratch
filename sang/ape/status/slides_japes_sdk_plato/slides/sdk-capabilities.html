The SDK

What a team gets without writing it

Grounded answers

An interactive agent answers from canonical objects and documents, and cites its sources.

Documents to data

Convert, classify, extract. Every value carries its source and confidence; weak values are refused, not written.

Orchestration

The Conductor runs declared pipelines with loops, durable resume and streamed progress.

Policy as data

Canonical policies, a deterministic assessment, and formal checks compiled from the same policy.

Evaluation

Gold cases, experiments against a baseline, and prompt optimization.

Feedback

Feedback is processed, reviewed and turned into evaluation cases.

These are the capabilities a pack or service gets by using the SDK rather than building them. Two points worth stressing for leadership: extraction refuses low-confidence values instead of writing degraded data, and policy lives as data that is checked deterministically and formally, so governance is not a prompt instruction.
