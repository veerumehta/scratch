The SDK

Five layers, each built on the one below

Pipelines

Chat, document ingest, investigation loop, policy extract, financial spread

Platform agents

Interactive, Document, Adjudication and Knowledge-graph agents, defined as data

Agent execution

Multi-provider LLM routing and fallback, tracing, cost and budget

Knowledge fabric

Canonical objects, knowledge graph, RAG, documents, governed guidance

Runtime

Queue processing, handlers, Kernel and Knowledge Hub clients, settings

Underneath it all: the OpenAI Agents SDK, made governed, traced and config-driven.

Japes SDK and Plato

04

Read it top down. A pipeline is a declared sequence of steps the Conductor executes, with loops, streaming and durable resume. Pipelines wire platform agents, which are task-specific agents configured as data. Those run through the agent execution layer, which handles provider routing, tracing and cost. Everything reads and writes through the knowledge fabric. The runtime at the bottom is the queue and service plumbing.
